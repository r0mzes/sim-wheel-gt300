# Проект: самодельный руль GT Ø300 для DIY-базы автосимулятора

## База и крепление
- База: `База.skp` (мотор, вал Ø8 с лыской; вал выступает ~30 мм, лыска ~20 мм).
- **Адаптер на вал** (печать PETG, 100 %): фланец Ø68×8, втулка Ø30×22, D-отверстие Ø8.2 / 7.6 по лыске, хомут (разрез + 2×M4 с гайками), стопор M4×10 в лыску, 6 гнёзд под гайки M5 на PCD 50.8.
- Ступица руля ↔ адаптер: 6×M5 на **PCD 50.8**.

## Система координат моделей
- мм; плоскость руля — XZ, ось руля — Y.
- y = 0 — плоскость крепления ступицы к адаптеру; −Y — к водителю, +Y — к мотору.
- Вынос обода (dish) 45 мм: плоскость разъёма половин обода y = −45.

## Обод (общий для всех вариантов)
- Ø300 после кожи; печатный Ø297, сечение 23×29 (овал), под кожу ~1.5 мм/сторону.
- 8 печатных полусегментов (4 передних + 4 задних по 90°), 210×60×14.5 мм, печать плоской стороной вниз без поддержек, фаска 0.4 от «слоновьей ноги».
- Стыки вразбежку: передние 1:30/4:30/7:30/10:30, задние 12/3/6/9 ч.
- Стяжка половин: 16 саморезов 2.9×16 через 22.5° на r = 129 (головки утоплены, всё под кожей, обод неразборный, плоскость разъёма на эпоксидке).
- Варианты с трубкой: канал Ø8.5 по r = 137 под Al трубку 8×1, согнутую в кольцо R137 (карбон не гнётся).

## Варианты спиц
| Вариант | Модель | Суть |

| Б (v8) | `GT300_v8_variantB_steel-bar.skp` | Стальная полоса 30×4, заготовка 110 мм, 2 гиба ~30°; печатная ступица Ø106×12, 2×M5 на спицу во вставки; конец полосы в пазу обода 30.4×4.2, глубина 6.5; обод с трубкой. |

## Кнопка сигнала (v9, построена на правках пользователя в v6)
- Печатный стакан Ø90×28 на лицевой стороне ступицы, прижат теми же 6 болтами PCD (M5×30 ISO 7380).
- Внутри: полка, лицевое кольцо, клавиша Ø72 (ход 0.7 мм), тактовая кнопка 12×12×7.3.
- Электроника: Seeed XIAO ESP32-C3 (BLE-геймпад, библиотека ESP32-BLE-Gamepad), LiPo 103450 2000 мА·ч, выключатель SS12D00, USB-C сверху.
- Позже сюда же можно подключить лепестки и кнопки на спицах.
- Модель: `models/GT300_v9_horn-button_BLE.skp`; дамп геометрии кнопки — `docs/v9_button_dump.json`.

## Крепёж и материалы (Украина)
- PETG 1.75; термовставки M4×4×5.6 (только AliExpress); винты ISO 7380 M4/M5; саморезы DIN 7981 2.9×16.
- Трубка АЛЮПРО 8×1 (Эпицентр); Poxipol; автокожа для руля.

## Структура репозитория
- `models/` — модели SketchUp по версиям.
- `stl/` — STL для печати (обод v5, ступица, спицы, адаптер на вал) + `README.txt` с настройками печати.
- `scripts/` — генераторы STL и контуров (Node + manifold-3d WASM; Python для превью).
- `docs/` — превью и JSON-дампы геометрии из SketchUp пользователя.

## Рабочие приёмы
- Геометрию `.skp` читать через Ruby Console в SketchUp пользователя (дамп в JSON → стейджинг); достраивать там же Ruby + Solid Tools, сохранять `save_copy`.
- STL с булевыми операциями: manifold-3d (WASM с jsdelivr) в Node — см. `scripts/README.md`.
